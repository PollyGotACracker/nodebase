# Query 스키마

## 입력

- `QUESTION`은 사용자 질문이다.

## 적용 기준

작업 전에 공통 지침의 경로 목록에서 폴더 구조, frontmatter 규격, Markdown 링크 규칙의 원문을 읽는다.
문서를 생성하거나 파일 이름을 바꿀 때 파일명 규칙의 원문을 읽는다.

## 절차

1. 질문에서 핵심어를 추출한다.
2. `wiki/index.md`와 관련 하위 목차를 읽고 필요한 문서 링크를 따라간다.
3. 목차에서 찾지 못한 항목은 핵심어와 별칭으로 `wiki/`를 검색한다.
4. 문서 본문과 존재하는 출처, 작성 및 검증 정보, 상태를 확인한다.
5. 출처의 적용 조건과 최신성을 대조하고 인용을 포함한 답변을 작성한다.
6. 확인한 사실과 추론, 상충 주장과 부족한 근거를 구분한다.
7. 새 지식을 남길 필요가 있으면 변경 대상과 내용을 제안한다.
   승인 후 관련 문서를 작성하거나 갱신한다.
8. 문서 변경 후 배치와 파일명, 메타데이터와 링크를 적용 기준의 원문과 대조하고 수동 목차를 갱신한다.
   `wiki/log.md`가 있으면 실제 변경을 기록한다.

## 진행 방식

1. 질문의 모든 항목에 답변한다.
2. 작성 또는 수정 전 내용을 제안하고 승인한 범위에 적용한다.
